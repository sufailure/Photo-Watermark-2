# Photo Watermark

本项目提供跨平台（Windows / macOS）图形界面工具，用于批量添加文本水印并导出图片。

## 功能特性

- 支持拖拽、文件选择器以及整个文件夹批量导入 JPEG / PNG / BMP / TIFF 图片。
- 在界面中显示缩略图列表，点击可切换预览。
- 实时预览水印效果，支持：
  - 自定义文本内容、字体、字号。
  - 颜色选择与透明度调节。
  - 九宫格快速定位或在预览图中拖拽任意摆放。
- 导出前可选择输出目录（默认禁止覆盖原目录）、输出格式（JPEG/PNG）、命名规则（保留/前缀/后缀）及 JPEG 质量。
- 水印模板管理：保存、加载、删除模板，启动时自动恢复上次设置。

## 环境准备

1. 安装 Python 3.9 或更新版本。
2. 安装依赖：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

## 运行

```powershell
python main.py
```

应用首次运行会在用户主目录下创建 `.photo_watermark/templates.json` 用于存储模板与最近一次设置。

## 使用说明

1. 通过工具栏按钮或拖拽导入图片/文件夹。
2. 在左侧缩略图列表中选择要预览的图片。
3. 在右侧面板调整水印文本、字体、颜色、透明度和位置。
4. 选择输出目录及命名方式后点击“立即导出”批量导出带水印的图片。
5. 如需保存当前参数，可在“水印模板”面板中点击“保存当前设置…”。
