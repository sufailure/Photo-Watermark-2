# Photo Watermark 图片批量加水印工具

Photo Watermark 是一款使用 PySide6 编写的桌面应用，支持 Windows。它提供直观的图形界面，可一次性导入多张图片，快速添加文本水印并导出处理结果，适用于摄影师、电商运营、设计师等需要日常批量出图的场景。

## ✨ 主要功能

- **多方式导入**：支持拖拽文件/文件夹、文件选择器、文件夹递归扫描，自动过滤常见图片格式（JPEG / PNG / BMP / TIFF）。
- **缩略图浏览**：左侧展示导入图片缩略图，点击即可切换预览，方便快速定位目标照片。
- **所见即所得预览**：
  - 输入任意文本，并选择字体与字号；
  - 颜色选择器与透明度滑块实时生效；
  - 九宫格按钮或直接拖拽，将水印精准放置在画面中；
  - 支持在缩放预览的同时保持水印位置比例，避免偏移。
- **导出配置灵活**：
  - 指定输出目录，防止误覆盖原图；
  - 输出 PNG 或 JPEG，JPEG 可调整压缩质量；
  - 文件命名支持保留原名或添加前缀、后缀，满足不同整理需求。
- **模板管理**：
  - 保存当前水印与导出参数为模板；
  - 随时切换、删除模板；
  - 自动记忆上次退出时的设置，省去重复操作。

## 🛠️ 环境准备

1. 安装 **Python 3.9 及以上版本**。
2. （推荐）创建虚拟环境并安装依赖：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

如果在 macOS/Linux 下，请将激活命令替换为相应脚本（例如 `source .venv/bin/activate`）。

## 🚀 启动应用

```powershell
python main.py
```

程序首次运行会在用户主目录创建 `.photo_watermark/templates.json`，用于存储模板及最近一次使用的配置。

## 📖 使用流程

1. **导入图片**：
   - 使用顶部工具栏的 “导入图片” 或 “导入文件夹”；
   - 也可直接将文件或文件夹拖拽到左侧缩略图列表。
2. **选择预览**：点击左侧缩略图，主视图会显示大图预览及当前水印。
3. **设置水印**：在右侧面板编辑文本内容、字体、字号、颜色和透明度；通过九宫格或拖拽调整位置。
4. **配置导出**：选择输出目录、文件格式、命名规则及（若为 JPEG）压缩质量。
5. **批量导出**：点击 “立即导出”，程序会在目标目录生成带水印的图片。
6. **保存模板（可选）**：若需复用当前设置，可在 “水印模板” 面板点击 “保存当前设置…”。

## ❓ 常见问题

- **看不到水印？** 请确认透明度设置、字体颜色与背景对比度是否合适，并尝试在预览区域拖动水印位置。
- **导出失败？** 检查输出目录是否与原图目录相同（默认禁止覆盖），或确认目标目录是否具备写入权限。
- **字体缺失？** 系统中未安装的字体将无法正常显示，可先在操作系统级别安装后重新启动应用。
